# Comparte Codex Usage Monitor

Texto sugerido para redes. No se publica automáticamente.

## Publicación

Creé una herramienta para un dolor de cabeza que tenía: perder de vista cuánto me queda de Codex durante la semana.

Codex Usage Monitor es un pequeño widget para Windows que muestra el saldo disponible, avisa al llegar al 70%, 50% y 30% restante y permite ver un ranking local de tokens por modelo y proyecto.

Es gratis y de código abierto. Descarga el ZIP, descomprímelo y abre el programa. Necesitas Windows x64 y Codex instalado con sesión iniciada.

Está en beta. El ranking de tokens no equivale a créditos ni dinero; es una referencia local. Es un proyecto independiente, no oficial de OpenAI.

Descarga y guía: https://github.com/jchaer-dot/codex-usage-monitor

Si te ayuda, compártelo. Si encuentras un fallo, repórtalo en GitHub sin incluir datos privados.
